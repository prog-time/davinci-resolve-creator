# davinci-resolve-creator

Claude Code skill `davinci-resolve-templates`: generates DaVinci Resolve
Fusion templates (`.setting` / `.drfx`) from a screenshot, a reference video,
or a description — titles, lower thirds, cards, animated badges — with
editable texts, colors, fonts and animation in the Inspector.

The skill itself lands in the `develop` branch.
