# Задача: создать скилл `davinci-resolve-templates`

Создай Claude Code скилл, который генерирует шаблоны для DaVinci Resolve (титры, плашки, lower thirds, карточки, генераторы, переходы) в виде Fusion-макросов `.setting` и упаковывает их в `.drfx`. Управлять Resolve скилл НЕ должен: только генерировать файлы и устанавливать их в папку шаблонов.

Основной сценарий: пользователь присылает картинку (скриншот плашки, карточки, титра). Скилл задаёт уточняющие вопросы, затем собирает шаблон, у которого в Inspector можно менять тексты, иконки, цвета, позицию и анимацию.

В приложенных файлах лежат наработки, которые уже проверены в Resolve. Возьми их за основу, не пиши с нуля:
- `fusion_lib.py` — билдер `.setting`: ноды, InstanceInput, UserControls, выражения, валидация;
- `pricing_card.py` — пример полноценного шаблона (тарифная карточка, 2 варианта, 81 опубликованный параметр);
- `tests_build.py` — пакет мини-тестов для диагностики.

## 1. Структура скилла

```
│   ├── verified.md            # что проверено в Resolve, а что нет (см. раздел 5)
│   ├── questions.md           # вопросы к пользователю с дефолтами
│   ├── design-rules.md        # правила построения шаблонов
│   └── examples/              # рабочие .setting (сгенерируй из pricing_card.py и тестов)
├── scripts/
│   ├── fusion_lib.py          # библиотека (доработать, см. раздел 6)
│   ├── analyze_image.py       # замеры с картинки: цвета HEX, границы, отступы
│   ├── pack_drfx.py           # упаковка .setting → .drfx
│   ├── install_macos.sh       # установка через unzip в папку Templates

```

Description в SKILL.md: «Генерация шаблонов DaVinci Resolve (Fusion .setting/.drfx) по картинке или описанию: титры, плашки, lower thirds, карточки, генераторы с редактируемыми параметрами в Inspector». Пиши description узко, чтобы скилл не срабатывал на обычный монтаж.

## 2. Workflow скилла (обязательный порядок)

1. **Анализ картинки.** Запусти `analyze_image.py`: снять цвета (медиана, минимум и максимум по регионам), найти границы элементов, отступы, радиусы. Перевести размеры в кадр 1920×1080 (или 1080×1920) через коэффициент масштаба.
2. **Вопросы одной пачкой** (см. раздел 3), у каждого вопроса дефолт. Если есть инструмент AskUserQuestion, используй его, максимум 4 вопроса за раз.
3. **Спецификация.** Показать таблицу слоёв: элемент, позиция в px, размер, цвет HEX, шрифт; список параметров Inspector; анимация. Дождаться подтверждения.
4. **Генерация** через `fusion_lib.py`: отдельный файл-спецификация в стиле `pricing_card.py`.
5. **Валидация** через `validate()`: баланс скобок, строки. Если в системе есть `luac`, дополнительно проверить синтаксис через `luac -p`.
6. **Упаковка** в `.drfx` (zip со структурой `Edit/Titles/<Группа>/<Имя>.setting`).
7. **Установка** скриптом (раздел 7) и инструкция, где искать шаблон.
8. **Сверка:** попросить скриншот из Resolve рядом с оригиналом, исправить расхождения. Калибровочные значения (масштаб текста и т. п.) записывать в `references/verified.md`.

## 3. Вопросы к пользователю

Не спрашивать то, что видно на картинке: расположение, цвета, пропорции, радиусы.

Обязательные (влияют на устройство шаблона):
1. Структура: один элемент с копиями на таймлайне или весь блок одним шаблоном. **Дефолт: один элемент + варианты.**
2. Что редактируется в Inspector: тексты, иконки, цвета, логотип. **Дефолт: все тексты и цвета.**
3. Поведение текста: фиксированная ширина или под текст, сколько строк. **Дефолт: фикс, 1 строка.**
4. Иконки: иконочный шрифт, слот под PNG или вектор. **Дефолт: Font Awesome 6 Free.**
5. Анимация. **Дефолт: выезд снизу + фейд, 12 кадров.**
6. Формат кадра, версия Resolve, ОС. **Дефолт: 1920×1080, Resolve 21, macOS.**

Уточняющие (только если по картинке непонятно): шрифт и **наличие кириллицы**; своя палитра или с картинки; тень, обводка, glass; одна плашка или серия.

## 4. Правила построения шаблонов (design-rules.md)

- **Варианты вместо переключателя.** Если нужен «обычный / выделенный» стиль, генерировать 2 файла с разными дефолтами. Переключатель через выражения заблокировал бы цветовые поля.
- **Мастер-ноды для цветов.** Цвет публикуется на одной ноде (например `Heading`), остальные ноды того же цвета ссылаются на неё выражением `Heading.Red1` и т. д.
- **Общие параметры** (масштаб текста, шаг списка, анимация) задаются как UserControls на одной Transform-ноде (`Card`) и публикуются через InstanceInput.
- **Text+ не переносит строки сам.** Переносы ставятся через `\n` в тексте. Для пунктов списка нужен лимит длины (примерно 38 символов при 17px на ширине 345px), об этом нужно предупреждать пользователя.
- **Иконки:** отдельная Text+ с иконочным шрифтом; пользователь меняет символ, копируя его через Copy Glyph на fontawesome.com.
- **Имена нод:** уникальные, понятные, с суффиксом. Не использовать служебные слова (`Name`, `Input`, `Output` и т. п.). Безопасный вариант: `TxtName`, `BgCard`, `XfCard`.
- **Подписи в Inspector** на русском, с префиксами для группировки: «Пункт 3: текст», «Кнопка: фон».
- **Анимация** на первом и последнем кадре даёт прозрачность. Это нужно явно сообщать пользователю, иначе он примет это за чёрный экран.
- **Шрифты:** только установленные у пользователя. Перед генерацией спрашивать или проверять (`fc-list` / `system_profiler SPFontsDataType`).

## 5. Что проверено в Resolve 21 (macOS), а что нет

**Работает (проверено):**
- макрос `MacroOperator` + `InstanceInput` / `InstanceOutput`, загрузка из `Templates/Edit/Titles/<папка>/`;
- `TextPlus` (кириллица, цвет `Red1/Green1/Blue1/Alpha1`, `Center`, `Size`, якоря `HorizontalLeftCenterRight` / `VerticalTopCenterBottom`);
- `Background` со сплошным цветом и с `Type = FuID{"Vertical"}` (градиент `TopLeft*` → `BottomLeft*`);
- `RectangleMask` через `EffectMask` у Background, `CornerRadius`;
- `Merge` поверх прозрачного `Background` (`TopLeftAlpha = 0`): альфа сохраняется;
- полная статичная карточка из 60+ нод, `Transform` с `UserControls`, публикация `Center` / `Size` / пользовательских слайдеров.

**Требует проверки (отметить в verified.md и уточнить у пользователя):**
- **Высота `RectangleMask`.** Тест с прямоугольником 600×300 px (Height = 300/1080) пользователь описал как «квадрат». Возможно, `Height` считается относительно **ширины** кадра (тогда Height = px/1920). Проверить тестом с явно вытянутым прямоугольником и исправить формулу в `rect_mask()`.
- Масштаб `Text+ Size` (сейчас `Size = px / 1920`, плюс ползунок «Масштаб текста» для калибровки).
- Значение `HorizontalJustificationNew = 0` для выравнивания влево в многострочном тексте.
- Выражения анимации: `time`, `comp.RenderEnd`, `iif`, `min`/`max`, `Point()`, ссылки `Card.AnimFrames`. Если не работают, перейти на ключевые кадры или на анимацию только появления.
- Установка перетаскиванием `.drfx` в окно Resolve ненадёжна. Основной способ — unzip (раздел 7).

## 6. Доработки `fusion_lib.py`

- Исправить `rect_mask()` после проверки высоты (раздел 5).
- Добавить ноды: `sRectangle` / `sEllipse` (shape-система), `Loader` (опционально), `Transform` с анимацией через ключевые кадры (`BezierSpline`) как альтернативу выражениям, `SoftGlow` / `DropShadow` для теней.
- Добавить `publish_font(op)`: Font и Style в одной ControlGroup.
- Генерация превью-PNG для Effects Library (файл с тем же именем рядом с `.setting`), отрисованного через PIL по спецификации.
- Проверка имён нод на служебные слова и уникальность.
- CLI: `python generate.py spec.py --variant all --pack --install`.

## 7. Установка (macOS)

Папка `~/Library/Application Support/Blackmagic Design/...` закрыта для удалённого доступа Claude, поэтому установка идёт командой пользователя в Терминале:

```bash
T="$HOME/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Templates" && mkdir -p "$T" && unzip -o "<путь к .drfx>" -d "$T"
```

После установки нужен перезапуск Resolve. Если закрывать его через `osascript -e 'quit app "DaVinci Resolve"'` при несохранённом проекте, вернётся ошибка `-128` (пользователь отменил закрытие). Правильно сначала попросить сохранить проект (Cmd+S) и закрыть вручную (Cmd+Q).

Где искать после установки: страница Edit → Effects → Toolbox → Titles → раздел Fusion Titles, группа = имя папки; либо поиск по названию.

Пути для других ОС оставить в `references/setting-format.md` с пометкой «не проверено»:
- Windows: `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates`
- Linux: `~/.local/share/DaVinciResolve/Fusion/Templates`

## 8. Диагностика («чёрный экран»)

Порядок проверки, зафиксировать в SKILL.md:
1. Плейхед стоит в середине клипа, а не на первом кадре (анимация).
2. Шаблон установлен через unzip, Resolve перезапущен.
3. Пакет мини-тестов `make_test_pack.py`:
   - Test 1 Text — красный текст;
   - Test 2 Background — зелёный кадр;
   - Test 3 Rect Mask — синий прямоугольник 2:1;
   - Test 4 Merge — белый текст на прозрачном фоне.
4. Бисекция шаблона: статичная версия без выражений → версия без Transform → только фон. Первый сломанный шаг указывает на виновника.
5. Попросить Workspace → Console и скриншот графа нод на странице Fusion.
